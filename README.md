# Cursor Finder

Cursor Finder highlights your pointer with animated effects. It lives in the macOS menu bar and supports a configurable shortcut, hold or toggle activation, multiple displays, and optional sound.

**[Download for Mac](https://github.com/jinuhwang/cursor-finder-community/releases/latest)** · macOS 13 or later · Apple silicon and Intel · Free

Open the DMG and drag **Cursor Finder** into **Applications**, then launch it from Applications. Open **Preferences…** from its menu bar icon to set your shortcut and effect. The direct-download version can check for signed updates through **Check for Updates…**. The App Store version receives updates through the App Store.

## Effects

Open **Effect Gallery…** from the menu bar. Select an effect to preview it, then choose **Use Effect**. Installed effects work offline. The gallery fetches a reviewed catalog from this repository; opening the app alone does not fetch the gallery.

Choose **Create** to build an effect from rings, rays and glows. **Customize** makes a separate copy of an existing effect. Adjust the layers, motion, color, size and speed, then save it to **My Effects**. Set hold or toggle activation in Preferences.

**Export…** saves a `.cfeffect` file you can send to another person. They can use the gallery's import button to load it. Effect files contain limited animation data, not executable code, scripts, shaders, external resources, sounds or tracking.

## Share with the gallery

1. Finish and test your effect. Choose a name and public creator name; you do not need to use your legal name.
2. Choose **Submit to Gallery…**. Save the `.cfeffect.txt` file. This text suffix makes the attachment compatible with GitHub.
3. The app opens the [effect submission form](https://github.com/jinuhwang/cursor-finder-community/issues/new?template=effect-submission.yml). Attach the exported text file and submit it using your GitHub account. Creating and importing effects in the app does not require an account.
4. A maintainer reviews the effect and its credits before adding it to the public catalog. Submitting a file does not publish it in the app automatically.

Use original work or material you have permission to share. Choose [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) to require attribution, or [CC0](https://creativecommons.org/publicdomain/zero/1.0/) for original effects you want to dedicate to the public domain. Keep existing attribution when adapting a CC BY effect. See [format and review rules](CONTRIBUTING.md).

To report an effect, choose **Report Effect…** in its menu, or email **mangocandy.studio@gmail.com** with its name and the problem. **Block Creator…** hides that creator's gallery entries and removes their installed effects. You can unblock creators at the bottom of the gallery window.
